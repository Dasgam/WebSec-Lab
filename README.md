# WebSec Lab

**WebSec Lab** — веб-платформа для изучения основ веб-безопасности и практического исследования распространённых уязвимостей в изолированной лабораторной среде.

Проект предназначен для обучения, демонстрации принципов работы веб-уязвимостей и анализа HTTP-запросов и ответов.

## Возможности

- **Лаборатории безопасности** — практические задания по распространённым веб-уязвимостям.
- **Reflected XSS** — изучение отражённых межсайтовых скриптовых атак.
- **Stored XSS** — изучение хранимых межсайтовых скриптовых атак.
- **CSRF** — изучение подделки межсайтовых запросов.
- **SQL Injection (SQLi)** — изучение уязвимостей внедрения SQL-кода.
- **HTTP-анализатор** — исследование HTTP-запросов и ответов.
- **Изолированный запуск лабораторий** — использование Docker-контейнеров для запуска учебных приложений.
- **Пользовательский интерфейс** — управление лабораториями и доступными инструментами через веб-интерфейс.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Dasgam/WebSec-Lab.git
cd WebSec-Lab
```

### 2. Запуск Backend

Открой терминал в папке проекта:

```bash
cd backend
python -m venv venv
```

Активация виртуального окружения в Windows CMD:

```bat
venv\Scripts\activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Применение миграций:

```bash
python manage.py migrate
```

Запуск сервера разработки:

```bash
python manage.py runserver
```

### 3. Запуск Frontend

Открой второй терминал:

```bash
cd frontend
npm install
npm run dev
```

Адрес frontend будет указан в выводе Vite, обычно это:

```text
http://localhost:5173
```

### 4. Docker-лаборатории

Для запуска лабораторных приложений необходим Docker Desktop. Перед запуском убедись, что Docker работает и доступны необходимые образы.

Параметры запуска контейнеров и портов зависят от конфигурации Backend.

## HTTP-анализатор

HTTP-анализатор предназначен для исследования HTTP-взаимодействий и просмотра ответов серверов.

При работе с анализатором следует учитывать сетевые ограничения и правила изоляции. Проверяй только собственные системы, локальные лаборатории или ресурсы, на тестирование которых у тебя есть разрешение.

## Безопасность

- Используй лаборатории исключительно в учебных целях.
- Не проводи тестирование чужих систем без разрешения.
- Не публикуй секреты, токены, пароли и содержимое файлов `.env`.
- Не выставляй уязвимые учебные приложения в публичную сеть.
- Перед запуском проверяй настройки Docker и сетевые ограничения.

## Назначение проекта

WebSec Lab разработан как учебный проект для демонстрации принципов веб-безопасности, изучения распространённых уязвимостей и практической работы с HTTP и Docker.
